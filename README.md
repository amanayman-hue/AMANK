# أمانك - Amank Family V2 💪❤️
أسرتك بأمان مع أمانك


تطبيق حماية عائلية مصري 100% - الأب (روحي الحر) يتابع ويحمي روحي 2,3,4,5 (أطفاله) بموافقتهم.

### 1. الرسالة الدائمة اللي طلبتها
- عند الأب: إشعار دائم لا يُغلق محتواه ( أسرتك بأمان مع أمانك 💪 )
- عند روحي 2,3,4,5: شاشة حماية + رسالة ( روحي انت بأمان مع أمانك ❤️ ) + تحذير ان الحجب شغال

### 2. لوحة تحكم روحي الحر (الرئيسية)
- زرار تتبع لروحي 2,3,4,5 والاختيار بينهم
- التحكم في تطبيقاتهم (قفل / فتح)
- معرفة الوقت اللي قضوه على الهاتف والتطبيقات
- معرفة موقعهم الجغرافي (بموافقتهم)
- زر تفعيل ابحث عن هاتفي في حالة الفقدان أو السرقة

### 3. نظام الاشتراك - فودافون كاش
- زر الاشتراك عن طريق فودافون كاش يختفي بعد الدفع
- يستبدل بكلمة مشترك وآمن مع عداد تنازلي
- تنبيه قبل انتهاء الاشتراك بـ 48 ساعة في الواجهة

*العروض:*
- 50 جنيه / شهر (روحي 2)
- 60 جنيه / شهر (حتى 3)
- 120 جنيه / 3 شهور - عرض التوفير
- 150 جنيه / 6 شهور - عرض العيلة

الدفع: تحويل على فودافون كاش + رفع سكرين شوت - تأكيد يدوي آمن.

### 4. كيف نبني الحلم ده؟ (الأكواد الحقيقية)
- AmankForegroundService: لعمل الإشعار الدائم Ongoing Notification
- DeviceAdmin: لمنع حذف التطبيق عند الأطفال
- UsageStatsManager: لمعرفة وقت التطبيقات
- FusedLocationProvider: للموقع الجغرافي بموافقة
- WorkManager: لتنبيه الـ 48 ساعة

### 5. الأمان والقانون
التطبيق لا يتجسس. التتبع يتم فقط بموافقة واضحة من روحي 2,3,4,5 داخل التطبيق. لحماية العائلة فقط.
